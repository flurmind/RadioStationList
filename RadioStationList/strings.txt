PLUGIN_RADIOSTATIONLIST_USE_ICON_PROXY_DESC
	EN	Implements a 2-strike system for downloading logos. Attempt 1 is always direct. If it fails (due to ISP blocks, network errors, or unprocessable links), Attempt 2 routes via the wsrv.nl CDN proxy when enabled, or retries directly when disabled. After 2 failed strikes, the logo URL is blacklisted and replaced with the default icon.
	RU	Использует систему из 2 попыток загрузки логотипов. 1-я попытка — всегда прямая. В случае ошибки (из-за блокировок провайдера, сетевых сбоев или проблем с обработкой в LMS) 2-я попытка выполняется через CDN-прокси wsrv.nl (если включено) или повторно напрямую (если выключено). После 2 ошибок URL логотипа банится и заменяется дефолтным.

RR_SEARCH_LIMIT_DESC
	EN	Number of stations loaded per API request. This value must be large enough so that search results overflow your screen height, otherwise infinite scrolling will not trigger. An optimal cache size also ensures faster simultaneous loading of direct logos on the search page.
	RU	Количество станций, загружаемых за один API-запрос. Оптимальный размер кэша также обеспечивает более быструю одновременную загрузку прямых логотипов на странице.
